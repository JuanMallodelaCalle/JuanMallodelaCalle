## 🏠 &nbsp;Welcome to JuanOS

<a href="https://juanos.pages.dev">
  <img src="miniatura-hello-world-b.jpg" alt="JuanOS: a 3D room with the caption Hello, world. Welcome to my portfolio" width="100%">
</a>

My portfolio is a room you can walk into. **JuanOS** is a 3D bedroom whose light follows your local time. Sit at the desk and the computer boots a small OS about me: my research, a travel gallery, a chess game against three versions of me and a terminal that hides a secret. 14 achievements, plus one hidden.

Built with TypeScript, React, Vite and Three.js, with Claude Code as a development partner.

## 🔬 &nbsp;Research: DREAM

**DREAM: A Multicultural Multimodal Dataset Linking Dialogues and Realistic Image Sequences**<br>
Juan Mallo de la Calle, Marcos Estecha-Garitagoitia, Ricardo Córdoba, Luis Fernando D'Haro · *LREC 2026*

<p align="center">
  <img src="https://github.com/JuanMallodelaCalle/personalized-ai-visual-summaries/raw/HEAD/docs/persona_chat_760_B.png" width="15%" alt="Synthetic DREAM portrait 1">
  <img src="https://github.com/JuanMallodelaCalle/personalized-ai-visual-summaries/raw/HEAD/docs/persona_chat_4513_B.png" width="15%" alt="Synthetic DREAM portrait 2">

  <br><sub>Six of the 2,000 DREAM portraits. All fully synthetic: no real person is depicted.</sub>
</p>

Long, persona-driven conversations are hard to review. DREAM turns them into storyboards: 1,000 dialogues from PersonaChat and ComperDial, each enriched with two multicultural persona profiles, a photorealistic portrait per speaker and a sequence of scene images for the moments that matter. It started as my Master's thesis at UPM and supports research on visual grounding of dialogue, identity consistency and bias in generated images.

| | |
| :--- | :--- |
| 📄 **Paper** | [LREC 2026 Proceedings](https://lrec.elra.info/lrec2026-main-728) |
| 📊 **Scale** | 1,000 dialogues · 2,000 personas and portraits · 6,950 scene images |
| 🤗 **Dataset** | [JuanMallo/dream-75pct](https://huggingface.co/datasets/JuanMallo/dream-75pct): a 75% public subset |
| ⚙️ **Pipeline** | [personalized-ai-visual-summaries](https://github.com/JuanMallodelaCalle/personalized-ai-visual-summaries): generation and evaluation pipeline (LLMs, VLMs, text-to-image, human and VLM evaluation) |
| 🧬 **Explorer** | [dream-persona-explorer](https://github.com/JuanMallodelaCalle/dream-persona-explorer): Streamlit dashboard to filter, map and quality-check the 2,000 personas |
